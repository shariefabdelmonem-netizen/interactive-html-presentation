ChatGPT · Custom GPT

  1. Go to Explore GPTs → Create and open the Configure tab.
  2. Name it "Interactive HTML Presentation".
  3. Paste the full instructions into Instructions.
  4. Turn on Web search and Canvas, then Create.

Gemini · Gem

  1. Open Gems → New Gem.
  2. Name it "Interactive HTML Presentation".
  3. Paste the full instructions into Instructions and save.
  4. In the chat, turn on Canvas to preview the slides.

Claude · Skill

  1. Download SKILL.md from the repo.
  2. Go to Settings → Capabilities → Skills and upload it.
  3. Ask: "Make an interactive presentation about …"

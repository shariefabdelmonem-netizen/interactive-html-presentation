الخطوات بالصور

قبل ما تبدأ

  • Claude بياخد ملف SKILL.md لوحده، أو ملف ZIP فيه SKILL.md. الأسهل ترفع SKILL.md.
  • لو صفحة Skills مش ظاهرة، شغّل Code execution and file creation من Settings → Capabilities.
الملفSKILL.mdأو ملف الـ ZIP، الاتنين شغالين
  1. افتح تطبيق Claude أو claude.ai، ودوس Customize في القائمة الجانبية.
  2. اتأكد إنك على تاب Skills، ودوس + Add فوق على اليمين.
  3. اختار Upload skill من القائمة.
  4. اسحب ملف SKILL.md في المربع أو دوس browse واختاره، وبعدين Upload. Claude بيعمل فحص أمان للملف وهو بيترفع.

تستخدمها إزاي

هتلاقيها في تاب Yours في نفس الصفحة. اطلب الحاجة عادي، وClaude بيستخدم الـ skill لوحده لما الطلب يناسبها، أو اذكر اسمها في طلبك، زي: "استخدم interactive-html-presentation واعملي عرض عن …"

قبل ما تبدأ

  • OpenAI بتقول إن الـ Skills متاحة لحسابات Business وEnterprise وHealthcare وEdu. لو حسابك Plus أو مجاني ممكن ما تلاقيش صفحة Skills، شوف الحل تحت في الأخطاء.
  • في حسابات الشغل، الأدمن ممكن يكون قافل رفع الـ skills.
  • أماكن القوايم في ChatGPT بتتغير كتير، فلو الاسم مختلف شوية دوّر على كلمة Skills.
الملفSKILL.mdأو ملف الـ ZIP، الاتنين شغالين
  1. افتح تطبيق ChatGPT، ودوس على أيقونة @ في الشريط الشمال عشان تفتح Customize. بعدين اختار Skills.
  2. دوس Add واختار Create skill.
  3. هيفتحلك شات فيه Skill Creator. دوس + وارفع ملف SKILL.md، واكتب: "Install this skill" وابعت. على موقع chatgpt.com ممكن تلاقي بدلها Create → Upload from your computer وترفع الملف على طول.
  4. لما يخلص التسطيب، هتلاقيها في صفحة Skills تحت Installed.

تستخدمها إزاي

اطلب الحاجة عادي، أو اكتب @ واختار الـ skill من القائمة.

قبل ما تبدأ

  • الرفع من gemini.google.com على الكمبيوتر أو تطبيق Gemini على الماك، مش من الموبايل.
  • Gemini بياخد ملف أو فولدر بس، من نوع PDF أو CSV أو PY أو TXT أو MD. يعني ما ترفعش ZIP، ارفع SKILL.md لوحده.
الملفSKILL.mdملف واحد، من غير فولدر ولا ZIP
  1. افتح gemini.google.com. من القائمة الجانبية دوس Customize، وبعدين تاب Skills فوق.
  2. دوس Create، واختار Upload من القائمة.
  3. اسحب ملف SKILL.md في المربع، أو دوس على files واختاره. وبعدين Continue.
  4. راجع الاسم والوصف واحفظ. هتلاقي الـ skill تحت Installed.

تستخدمها إزاي

Gemini بيستخدمها لوحده لما الطلب يناسبها. أو اكتب @ أو / في خانة الكتابة واختار اسمها.

لو ظهرلك خطأ

"The skill folder contains a file with an unsupported file type"

فيه ملف من نوع مش مقبول. أشهر الأسباب:

  • رفعت ZIP على Gemini: Gemini مش بياخد ZIP. ارفع SKILL.md لوحده.
  • ملف مخفي من الماك: لما تفتح فولدر في Finder، الماك بيحط جواه ملف مخفي اسمه .DS_Store، والـ AI بيرفضه.
  • حمّلت الـ repo كله: زرار Code → Download ZIP في GitHub بينزّل كل الملفات، صور وصفحات. حمّل ملف الـ skill بس.
الماك فك الـ ZIP لوحده بعد التحميل

متصفح Safari بيفك ملفات ZIP تلقائياً. لو محتاج ترفع ZIP:

  • حمّل الملف من Chrome أو Edge بدل Safari.
  • أو من Safari → Settings → General اقفل Open "safe" files after downloading، وحمّله تاني.
Claude بيقول إن اسم الفولدر مش مطابق (لو رفعت ZIP)

اسم الفولدر جوه الـ ZIP لازم يكون بالظبط نفس الـ name المكتوب أول ملف SKILL.md: حروف إنجليزي صغيرة وبينها شرطات، زي interactive-html-presentation.

مش لاقي صفحة Skills خالص
  • Claude: شغّل Code execution and file creation الأول. ولو حسابك Team أو Enterprise، اطلب من الأدمن يفعّل الـ Skills.
  • ChatGPT: غالباً خطة حسابك مش من الخطط المتاحة. الحل البديل: اعمل Project والصق محتوى SKILL.md في التعليمات بتاعته.
  • Gemini: افتحه من الكمبيوتر مش الموبايل. ولو داخل بحساب شغل أو مدرسة، الميزة لسه مش متاحة له.
اترفعت بس الـ AI مش بيستخدمها
  • اتأكد إن الـ skill شغالة في القائمة، مش مقفولة.
  • نادِيها بالاسم: اذكر اسمها في طلبك في Claude، أو اكتب @ في ChatGPT وGemini واختارها.
  • اكتب طلبك بكلمات قريبة من وصف الـ skill، زي "اعملي عرض تفاعلي عن …".
مش عايز أرفع حاجة، عايز أجرّب بس

افتح SKILL.md، انسخ كل اللي فيه، والصقه في أول رسالة في أي شات، وقول "اتبع التعليمات دي". هتشتغل في المحادثة دي بس.

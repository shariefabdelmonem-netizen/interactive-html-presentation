يعني إيه Skill؟ ملف تعليمات بتحفظه مرة واحدة، والـ AI يرجعله لوحده كل ما تطلب الحاجة اللي هو معمول لها. بدل ما تلصق نفس البرومبت الطويل كل مرة.

  • شغّل Code execution and file creation من Settings → Capabilities. الـ skills ما بتشتغلش من غيره.
  • الملف لازم يكون ZIP، وجواه فولدر اسمه نفس اسم الـ skill، وجوه الفولدر SKILL.md.

  2. روح لصفحة الـ Skills.
    Customize←Skills
    في بعض الحسابات بتلاقيها في Settings → Capabilities تحت قسم Skills.
  3. دوس + وبعدين Create skill، واختار Upload a skill.
  4. اختار ملف الـ ZIP أو اسحبه في المربع.
  5. هتلاقي الـ skill في القائمة. اتأكد إن المفتاح اللي جنبها شغال.

لو ظهرلك خطأ

"The skill folder contains a file with an unsupported file type"

فيه ملف زيادة جوه الفولدر اللي رفعته. أشهر سببين:

  • ملف مخفي من الماك: لما تفتح فولدر في Finder، الماك بيحط جواه ملف مخفي اسمه .DS_Store، والـ AI بيرفضه.
  • حمّلت الـ repo كله: زرار Code → Download ZIP في GitHub بينزّل كل الملفات، صور وصفحات. حمّل ملف الـ skill بس.

الحل: في Gemini ارفع SKILL.md لوحده. في Claude وChatGPT ارفع ملف الـ ZIP الجاهز زي ما هو.

الماك فك الـ ZIP لوحده بعد التحميل

متصفح Safari بيفك ملفات ZIP تلقائياً. عندك حلّين:

  • حمّل الملف من Chrome أو Edge بدل Safari.
  • أو من Safari → Settings → General اقفل Open "safe" files after downloading، وحمّله تاني.
Claude بيقول إن اسم الفولدر مش مطابق

اسم الفولدر جوه الـ ZIP لازم يكون بالظبط نفس الـ name المكتوب أول ملف SKILL.md: حروف إنجليزي صغيرة وبينها شرطات، زي interactive-html-presentation.

مش لاقي صفحة Skills خالص
  • Claude: شغّل Code execution and file creation الأول. ولو حسابك Team أو Enterprise، اطلب من الأدمن يفعّل الـ Skills.
  • ChatGPT: غالباً خطة حسابك مش من الخطط المتاحة. الحل البديل: اعمل Project والصق محتوى SKILL.md في التعليمات بتاعته.
  • Gemini: افتحه من الكمبيوتر مش الموبايل. ولو داخل بحساب شغل أو مدرسة، الميزة لسه مش متاحة له.
اترفعت بس الـ AI مش بيستخدمها
  • اتأكد إن الـ skill شغالة في القائمة، مش مقفولة.
  • نادِيها بالاسم: اذكر اسمها في طلبك في Claude، أو اكتب / في Gemini و@ في ChatGPT واختارها.
  • اكتب طلبك بكلمات قريبة من وصف الـ skill، زي "اعملي عرض تفاعلي عن …".
مش عايز أرفع حاجة، عايز أجرّب بس

افتح SKILL.md، انسخ كل اللي فيه، والصقه في أول رسالة في أي شات، وقول "اتبع التعليمات دي". هتشتغل في المحادثة دي بس.
